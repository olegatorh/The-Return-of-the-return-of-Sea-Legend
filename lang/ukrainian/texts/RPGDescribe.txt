Strength
{
Груба фізична сила. Потрібно для того, щоб сильно ударити, кинути далеко і багато витягнути. Це впливає на виносливий вага і кількість очок життя. Орієнтована характеристика для навичок, що вимагають великих фізичних зусиль, особливо важких і середніх зброї, навичок зброї.
}

Perception
{
Відчуття. Можливість бачити і чути. Без хорошого озорника ядра пушек навряд чи будуть літати в сторону ворога. Особливо сильно впливає на майстерність м'ячність, прихованість.
}

Endurance
{
Витривалість. Необхідна для того, щоб люди пережили важку піратську професію. Вони потрібні потенційним клієнтам. Ремонт і захист найсильніше залежать від цієї характеристики, так само як зростання очок життя і переносимого ваги.
}

Charisma
{
Зрозуміло. Результат поєднання мужнього пораненого обличчя і добре підвешеного мови. Привабливому персонажу не потрібно звертатися до сили, щоб захопити товар щасливого торговця - він його віддасть сам. За ним підуть кращі люди, а найкрасивіші жінки чекають у кожному порту. Обум - необхідний атрибут для таких навичок, як авторитет і комерція. Це впливає на кількість офіцерів, які приєднуються.
}

Intellect
{
Інтелект. Знання, мудрість і здатність приймати рішення швидко. Для розумного персонажа не буде складним як швидко перезавантажувати зброю, так і знизити ціни в магазині. Використання навигаційних приладів також вимагає розуму. Це впливає на комерцію, зброю, навігацію.
}

Agility
{
Ловкость. Координація рухів і провідність рук. У неловкого людини меч застрягне в ножах, а абордовий крюк застрягне за штани свого власника. Необхідні для таких навичок, як легка і середня зброя, пістолети, абордаж. Це впливає на кількість відскоків у бою.
}

Luck
{
Що можна сказати про щастя? Ми джентльмени, якщо є удача, а без удачи джентльмени не можуть бути. Допомагає там, де нічого не вистачає. Куля пройде мимо, а ворог пройде мимо і не помітить. Це впливає на навички пістолета, щастя, таємницю
}

FencingLight
{
Здатність користуватися легкою зброєю - переважно рапірами і невеликими інструментами вбивства. Це залежить від розуму і сприйняття. (A*0.9+P*0.1)
}

Fencing
{
Здатність керувати мечами і шашками - зброя, яка вимагає не тільки сили, але і певної сноровації. (S*0.6 +A*0.4)
}

FencingHeavy
{
Владіння важкими палошами і мечами вимагає безліч фізичної сили. (S*0.9 + E*0.1)
}

Pistol
{
Можливість використовувати високотехнологічні пристрої, здатні відправляти маленькі свинцові шари на великі відстані. Вони вимагають майстерності і певної удачі. Хто знає, куди лятить пуля. (A*0.5 + L*0.5)
}

Fortune
{
Це удача. Вона - щастя. Потрібно всюди. (L)
}

Leadership
{
Авторитет. Коли люди бачать, що ви не згубитеся з вами в будь-якій переробці, вони починають вірити в вас, і ось таверни наповнені бажання приєднатися до вас на походах, а кораблі ворога здаються, не побачивши вашого прапора. І якщо авторитет високий, ви можете бути впевнені - ваші люди беруть на борту самого морського д'явола. Без чарів тут нікуди не може бути, і розум не перешкоджає. (I*0.1+C*0.9)
}

Commerce
{
Торгівля. Можливість продати дешевле те, що я купив вчора дешевше. Знання вигідних торгових маршрутів, ділові стосунки і дружні стосунки з власниками магазинів - все це наповнює кишені приємною тягою і дозволяє не думати про такі дрібниці, як зарплата команди або відсутність парусів у триуме. Це вимагає розуму і певного очарування. (I*0.8+C*0.2)
}

Accuracy
{
Молодість. Однією з найнеобхідніших якостей для морського простору. Справжній капітан не буде витрачати порошок і ядра на те, щоб стримувати всю рибу в окрузі, кожен залп - точно на мету! І коли солевий вітер розкидає порожнечий дим над капітанським мостом, горизонт повинен бути чистим від ворожих згуб! Без сприйняття і певної удачі тут не вийде. (P*0.8+L*0.2)
}

Cannons
{
Інструменти. Швидко об'єднувати зброю, швидко підтягнути, і поки голоси стрільби ще не стихаються серед переборів - знову очистити, забивати, затягнути, не забувати своєчасно затягнути пушку водою, щоб не перегрітися... Між громом і пламом смертоносної битви - нічого ліпшого - зарядити, підтягнути, зарядити! Це вимагає розуму і сили. (I*0.6+S*0.4)
}

Sailing
{
Навігація. Можливість привести корабель до порту через шторм і туман. Можливість користуватися навигаційними приборами і керувати ескадрами. Найбільший і грозний корабель літає, як птах, легко підкоряючись жорсткій руці досвідченого шкіпера. Це залежить від сприйняття та інтелекту. (P*0.2+I*0.8)
}

Repair
{
Починайте. Коли противник наносить на ваш корабель ядерний град, розкидаючи в кріпки борту і перетворюючи пару в решетку, коли під ударами шквалу розривається корпус, а вітер рває снаряд, як нитки - виправлення стає найважливішим з навичок корабля. Тут головне - терпіння, але і без спостереження не обійтися. (P*0.2+E*0.8)
}

Grappling
{
Абордаж. Тобто піднести корабель до борту ворога, з першого разу кінути котів і лавиною звалитися на трепечучого противника, ураганом проникнути на палуби і взяти ворожний корабель як заслужену нагороду - все це вимагає значного снору і досвіду, але багата виловка легко компенсує всі зусилля. Потрібно майстерність і інтелект. (A*0.7+I*0.3)
}

Defence
{
Захист. З дня в день команда з кораблем з'єднується, і ось кожен матрос вже стоїть десятки салаг з таверни. Захистити своїх людей під час бою, не дозволити їм безглуздо і безглуздо загинути - це завдання хорошого капітана. Виносливість і чарівність однаково важливі в мобілізації екіпажу для захисту корабля. (C*0.5+E*0.5)
}

Sneak
{
Таємність. Незнайомно проїжджаючи через ворожу охорону, прятаючись в безкрайній океанічній пустелі від переслідувачів або, як гром серед ясного неба, падаючи на небрежного ворога - хороший капітан повинен володіти цим навичками. Це неможливо без великої удачі і спостереження. (P*0.5+L*0.5)
}
